# B09 - Experimental design for fully nonlinear source location problems: which method should I choose? (classical baseline for seismic network design)
- Authors: H. Bloem, A. Curtis, H. Maurer
- Year: 2020; Geophysical Journal International 223(2), 944-958, doi:10.1093/gji/ggaa358
- URL: https://academic.oup.com/gji/article/223/2/944/5877909
- Type: peer-reviewed; classical statistical experimental design
- Scores: credibility 5, recency 3, bias 1

## Verbatim quotes
1. "the goal of SED is to define a surface monitoring network that optimally constrains this set of source locations given the data that would be observed."
2. "We find that DN-optimization provides the best results both in terms of performance and compute time."
3. "Maximum entropy design is shown to be effectively impractical due to the large number of samples and long compute times required."

## Relevance
Gives the seismological objectives (Bayesian D-optimal, maximum entropy, DN) a QUBO would have to approximate. Maximum entropy is the MI-style family of B01. No quantum content.

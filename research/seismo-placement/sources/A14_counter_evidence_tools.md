# Counter-evidence: network-design software that exists
- SN-CAST: Mollhoff, Bean, Baptie 2019, J. Seismology 23, 493-504, DOI 10.1007/s10950-019-09819-0 (verified Crossref). Detection-capability mapping, aimed at permanent regional networks; abstract not seen, the "can design new network geometry" claim is from a search summary (unverified).
- AuScope Seismic Network Design App, https://www.auscope.org.au/posts/sensi (page fetched). Type: institutional news; credibility 3, recency 4, bias 4 (promotional).
  - Quote: "a free tool that allows seismologists to design and optimise seismic arrays"
  - Quote: "For cost reasons, it is important to optimise network design prior to deploying seismometers in the field."
  - Pre-deployment design; not a post-earthquake recommender.
- Antunes et al. (European Geothermal Congress 2025), NetOpt3D / Python toolbox: PDF blocked; details from search summary only, unverified.
- Wilson, Ringler, Storm, Anthony 2019, "Rapid Station and Network Quality Analysis for Temporary Deployments", SRL, DOI 10.1785/0220180365 (metadata verified, abstract not seen): quality assessment of temporary arrays, not siting.
- Searches for GitHub tools recommending sites after an earthquake returned nothing relevant. GFZ HART (AlbACa 2019 Albania, 30 stations) and EarthScope RAMP/FlexiRAMP: only logistics/spacing rationale seen (summary-level); no siting algorithm found.
- Scores: mixed 2-4.
